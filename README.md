## The day's stories

The poster carries six real stories first reported on 22 November 2026:

1. **Climate talks collapse** — the UN COP31 summit in Türkiye ran two days
   into overtime and ended with no deal; fossil fuels went unmentioned in
   the draft text.
2. **Hormuz standoff** — Iran said two supertankers hit naval mines east of
   the Strait of Hormuz; the US warned Iran off testing the blockade.
3. **Kyiv building hit, 3 dead** — a Russian attack near Kyiv struck an
   apartment building, killing 3; Ukraine separately claimed a drone attack
   sank the Russian warship Merkury off Benghazi, Libya.
4. **Delta outage: 1,600 flights delayed** — a Delta Air Lines system outage
   (weight-and-balance software) delayed more than 1,600 flights; the FAA
   briefly halted Delta flights to Atlanta.
5. **12,000 evacuated at Manchester arena** — more than 12,000 people were
   evacuated from the Co-op Live arena during a Don Toliver concert after an
   unknown substance filled the venue.
6. **Cartel boss captured in Mexico** — cartel leader "El Chapo Isidro" was
   captured in northern Mexico in a firefight that left 11 dead.

## How it works

`main.ts` copies the prepared poster (`entry.png`, 1024×1024) to the output
directory the grader provides. No network, no dependencies: Node 22 standard
library only, and both runs write the same bytes.

Built with AI assistance (Muse, Meta) — poster artwork generated by an
image model from the day's verified headlines, code written in the agent
session bundled with the submission.
